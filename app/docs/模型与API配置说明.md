# 模型与 API 配置说明

## 基本概念

- **连接**：一组「服务商地址 + 接口协议 + API Key + 模型」的配置。同一个服务商可以添加多个连接，例如分别使用不同的型号。
- **模型**：服务商提供的具体型号，以模型 ID 区分，例如 `deepseek-flash`。
- **用途**：连接添加后不会自动启用，需要在「用途分配」中指定它用于默认聊天、识图，或某个群和私聊。
- 三者的关系：先添加连接并检测通过，再在「用途分配」中选择由哪个连接负责哪种用途。保存连接不会改变正在使用的模型。

## 添加连接的步骤

1. 点击右上角的「添加连接」，在窗口左侧选择服务商。
2. 填写 API Key，点击「检测连接」。检测会直接请求服务商，几秒内显示结果，并列出该密钥可以使用的模型。
3. 在模型列表中选择型号（标有「推荐」的是预设型号），按需要选择思考程度和图片输入。
4. 点击「保存连接」。保存前会对所选模型再发起一次简短的请求进行验证，可能产生极少量用量。
5. 在「用途分配」中，把默认聊天或识图改为新添加的连接。

使用中转站或其他服务商时，在左侧选择「自定义 / 中转站」，然后在「高级」分页填写地址、协议和模型 ID。

## 各服务商的密钥获取与注意事项

- **OpenAI**：在 OpenAI Platform（https://platform.openai.com/api-keys）创建密钥。预设使用 Responses 接口。账户需要有可用余额。
- **Anthropic / Claude**：在 Claude Console（https://platform.claude.com）的 Settings → API keys 中创建密钥。使用可跨多个工作区的密钥时，需要在「额外请求头」中填写 `anthropic-workspace-id`。
- **DeepSeek**：在 DeepSeek 开放平台（https://platform.deepseek.com/api_keys）创建密钥。预设型号支持图片输入，其他型号的图片能力需要单独确认。
- **Kimi**：在 Kimi 开放平台（https://platform.kimi.com）创建密钥。platform.kimi.com 与 platform.kimi.ai 的密钥不能混用，预设地址对应 platform.kimi.com。预设型号始终思考，图片以 base64 形式发送，不支持公网图片链接。
- **Gemini**：在 Google AI Studio（https://aistudio.google.com/apikey）创建密钥。预设型号的思考程度可选择低、中、高；未选择时，AstrBot 按「高」发送。
- **Grok**：在 xAI Console（https://console.x.ai）创建密钥。预设型号始终思考，不能关闭。
- **通义千问**：在阿里云百炼控制台（https://bailian.console.aliyun.com/cn-beijing/settings/api-key）创建密钥。密钥分地域使用，不能跨地域；API 基础地址必须与密钥的地域和计费方案一致，否则会提示密钥无效。Token Plan、Coding Plan 的专用密钥只能用于编程工具，不能用于 bot。
- **豆包**：在火山方舟控制台（https://console.volcengine.com/ark）切换到目标项目，在「API Key 管理」中创建密钥。模型 ID 可以填写通用型号，也可以填写自己创建的推理接入点 ID。
- **MiniMax**：在 MiniMax 开放平台（https://platform.minimax.cn）的「账户管理 → 接口密钥」中创建密钥。预设型号始终思考，不能关闭。
- **MiMo / 小米**：在小米 MiMo 开放平台（https://mimo.mi.com）创建密钥。
- **GLM / 智谱**：在智谱开放平台（https://bigmodel.cn/usercenter/proj-mgmt/apikeys）创建密钥。预设的 Flash 型号支持图片且始终思考；`glm-5.3` 是纯文本型号，不能用于识图。
- **LongCat**：在 LongCat API 开放平台（https://longcat.chat/platform/api_keys）创建密钥。开启思考时服务商会固定使用较高的温度。

各服务商的价格以其官方价格页为准。控制台的「用量与费用」只统计 token 数量，不按价格换算。

## 自定义中转站

- **API 基础地址**：填写到版本号为止，例如 `https://api.example.com/v1`。不要包含 `/chat/completions` 这类具体接口路径，也不要在地址中写入密钥或查询参数。
- **接口协议**：绝大多数中转站使用「Chat Completions」。只有中转站明确说明支持时才选择 Responses、Anthropic 或 Gemini。
- **模型 ID**：以中转站后台显示的名称为准，大小写和连字符都需要一致。中转站提供模型列表时，检测连接后可以直接选择。
- **思考程度**：自定义中转按所选协议的通用写法发送参数，默认选项为「不指定」，即不发送思考参数。中转站的写法可能不同，请以中转站的说明文档为准，必要时在「其他参数」中填写。

## 检测结果的含义

- **连接正常**：密钥有效，已读取到模型列表。保存前还会对所选模型验证一次。
- **该服务商未提供模型列表**：服务商没有提供读取模型列表的接口。请在「高级」分页手动填写模型 ID，保存前的验证会确认密钥和模型是否可用。
- **密钥无效或没有权限**：检查 API Key 是否填写完整、是否已过期、是否属于当前服务商和地域。
- **地址或接口协议不匹配**：检查 API 基础地址是否填写到版本号为止，以及接口协议是否与服务商一致。
- **模型 ID 无法使用**：服务商不认识该型号，或当前密钥无权使用。重新选择模型或核对拼写。
- **余额不足或请求过于频繁**：到服务商控制台查看余额和限额。
- **服务商拒绝了验证请求**：多见于型号不支持当前参数。检查「其他参数」和思考程度。
- **网络不通或超时**：检查网络连接；15 秒内没有响应时会提示超时。
- **证书或代理问题**：检查系统代理设置；使用中转站时确认地址以 `https://` 开头且证书有效。

检测和验证的结果只显示经过整理的说明，不显示服务商的原始报错，任何结果和日志中都不会出现密钥。

## 思考程度

- 思考程度越高，bot 回答前的推理越充分，回答越慢，消耗的 token 越多。日常聊天建议选择「低」，需要推理的问题可以选择「中」或「高」。
- 界面只显示所选型号支持的档位：始终思考的型号不显示「关闭」，只能开关思考的型号显示「关闭 / 开启」，不提供思考选项的型号会隐藏此项。
- 已有连接中如果写有控制台无法识别的思考参数，此项显示为「自定义」，在主动改选之前不会覆盖原有参数。
- 思考程度会改变发送给服务商的请求参数；修改后，之前的提示词缓存可能失效一次。
- 「其他参数」与思考程度设置了同一参数时，以思考程度的选项为准。

## 图片输入与识图

- 「图片输入」表示该型号能否直接接收图片。检测到的模型列表中标有「识图」的型号支持图片；没有标注时，请以服务商说明为准。
- 只有开启了图片输入的连接才能被选为识图模型。识图模型负责把群聊中的图片转为文字描述，再交给聊天模型回复。
- 更换模型 ID 后，图片输入需要重新确认。

## 按会话分配模型

- 「用途分配 → 会话单独指定」列出白名单中的群和私聊，可以让某个群使用与默认聊天不同的模型。
- 单独指定后，该会话不再跟随默认聊天模型；改回默认聊天模型即可恢复跟随。
- 正在作为默认聊天、识图或某个会话模型的连接不能直接删除，需要先在「用途分配」中改为其他连接。

## 常见问题

- **检测通过，但 bot 仍然没有使用新模型**：保存连接不会切换正在使用的模型，请在「用途分配」中应用。
- **修改了 API 基础地址后提示需要重新填写密钥**：为防止密钥被发送到新的地址，更换地址时需要重新填写对应的密钥。
- **检测时提示「该连接正在检测中」**：同一个连接同时只进行一次检测，请等待上一次完成。
- **安装向导中能否检测**：可以。安装向导的「模型 API」一步同样提供「检测连接」，此时 AstrBot 尚未运行，检测由控制台直接请求服务商。

文中各服务商的地址、型号和注意事项核对于 2026-11-12，以各服务商的官方文档为准。

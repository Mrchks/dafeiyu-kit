# 控制台视觉规范

v1.4.0 起的界面规范。改界面前先看这份，新加的页面、弹窗照着做，保持整个控制台一个样子。

## 原则

- 简约、中性：底色和文字只用灰阶，彩色只用来表示状态（绿 正常 / 橙 需处理 / 红 出错）和链接。
- 用细线分层，少用阴影：卡片 1px 边框 + 极浅阴影，只有弹窗、提示、任务卡用明显的浮层阴影。
- 主要按钮是黑底白字（深色模式下反过来），一个区域最多一个主要按钮。
- 不用网页字体，全部用系统字体；不放装饰图、渐变、表情符号。
- 布局稳定：状态变化只改文字和颜色，不改尺寸；结果往下长，不把上面的东西顶走。
- 所有页面同一个框架：同样的容器（最大 1360px、居中、内边距 28 × 40）和同样高度的标题区，标题、说明、右上按钮在每一页的位置都一样，切页面时不跳。原版后台页也一样，内嵌网页放在带描边的 `.framebox` 里。
- 主区域始终给滚动条留位置（`scrollbar-gutter: stable`），有没有滚动条内容都不左右挪。
- 一屏放得下的页面整页撑满窗口、不出滚动条（页面加 `fit` 类，主体区域 `flex:1` 并在内部滚动）；设置类长表单按分区切换，不做长滚动页。
- 并排的卡片必须等高。不用瀑布流、不让两列一高一矮；内容长短不一时改成单列，或者给固定高度、在卡片里面滚动。
- 不出现浏览器自带的控件样子：勾选框、单选框、下拉、滑块、数字框、日期选择、悬停提示、确认框全部用控制台自己画的版本。

## 颜色（CSS 变量，定义在 index.html 的 :root）

| 用途 | 变量 | 浅色 | 深色 |
|---|---|---|---|
| 页面底色 | `--bg` | #f7f7f6 | #0c0c0d |
| 卡片 | `--panel` | #ffffff | #141416 |
| 次级底色 | `--panel2` | #f2f2f0 | #1c1c1f |
| 分隔线 | `--line` / `--line2` | #e7e7e4 / #d6d6d1 | #26262a / #34343a |
| 文字 | `--text` / `--text2` | #18181b / #3f3f46 | #ededef / #c9c9ce |
| 次要文字 | `--muted` / `--faint` | #71717a / #a1a1aa | #8b8b93 / #5f5f66 |
| 主要按钮 | `--primary` | #18181b | #ededef |
| 链接、焦点框 | `--accent` | #2f5bd3 | #7c9cf2 |
| 状态 | `--good` `--warn` `--bad`（各带 `-soft` 浅底） | | |

深色模式跟随系统（`prefers-color-scheme`），只换变量，不另写组件样式。

## 字号

12（标签、表头、说明）· 13（正文辅助、表格）· 14（正文）· 15–16（分区标题、弹窗标题）· 20（状态卡状态）· 22（页面标题）· 26（大数字）。字重只用 400 / 500 / 600。

## 间距、圆角、阴影

- 间距用 4 的倍数：常用 8 / 12 / 16 / 24 / 32 / 40。页面内边距 28 × 40，手机 20 × 16。
- 圆角：8（按钮、输入框）· 12（卡片、分区）· 16（弹窗）。
- 阴影两级：`--shadow-1`（卡片，几乎看不见）和 `--shadow-2`（弹窗、提示、任务卡）。

## 图标

线性图标，16px，描边 1.75，圆头圆角，颜色跟随文字（`currentColor`）。直接内联 SVG，不引图标库。

## 动效

- 时长 150–300ms。缓动：`--ease`（一般过渡）、`--out`（出现、滑动，快起慢停）、`--spring`（勾选、开关圆钮、完成图标，带一点回弹）。
- 出现：淡入 + 轻微上移或缩放；消失：淡出后再收起占位，下面的东西平滑补上，不跳。
- 切页面：标题区不做动画，只有下面的内容淡入。整页或撑满一屏的区域不做位移动画——位移会让页面在动画那一瞬间多出几像素、冒出滚动条，内容跟着左右顿一下。
- 选中状态用「滑动底块」：侧栏、分段切换、设置目录的选中底色从旧位置滑到新位置。
- 按下：按钮缩到 0.97，勾选框缩到 0.86。
- 系统开了「减少动态效果」时全部关掉。

## 常用组件

- 页面标题：`.head`（固定 58px 高；左边 `h1` + `.sub` 一句说明，右边 `.act` 放页面级按钮或分段切换）。说明只写一行，放不下就省略，完整说明写进 `data-tip`，鼠标放上去看。
- 分区：`.section`；标题右侧要放按钮时用 `.sh`。标题带说明时，把 `h2` 和 `.hint` 放进 `.sh-t`（左侧上下排列），按钮放 `.act`（靠右，高 32px），两者互不挤占；说明文字行高 1.7，与下方内容间隔 12–16px。
- 弹窗高度固定：切换选项、显示报错都不改变窗口尺寸；需要展示更多内容时另开一个窗口，不在原窗口内展开。
- 总览：`.banner` 状态条（固定 52px 高，一行字，超长省略）、`.scard` 状态卡（`.top` 标签、`.st` 状态、`.kvs` 键值行、`.bot` 底部文字按钮）。
- 开关列表：`.trow`（名称 + 一行说明 + 开关）；表单行：`.field`（左标签右控件，下面 `.tip` 说明）。
- 分段切换：`.seg`（选中底块自动滑动）；状态小标签：`.pill.g / .w / .b`；删除用同尺寸的「已删除 · 撤销」占位。
- 下拉：照常写 `<select>`，页面会自动换成自己画的按钮和菜单（`.csel` / `.cmenu`），代码读写 `value` 不用改。
- 数字框：`<input type="number">` 自动加上 − / +。悬停提示：照常写 `title`，自动换成小气泡。
- 日期范围：`dpOpen(按钮, 范围, 回调)`，左边常用时间段，右边日历选起止，再填具体时间。
- 右下角：`toast(文字, 'ok' | 'err' | '', 毫秒, [[按钮名, 函数]])`，第一行是标题、换行后是说明；失败的不自动消失。
- 确认框用 `ask()`，按 Esc 等于取消。

## 文字

界面上的全部文字都使用规范的说明性表述，包括标题、按钮、标签页、选项名，以及说明、提示和报错信息；不使用口语化表达。规范不等于生硬：句子要完整、通顺，按自然语序书写（参考 oil-tone 写作规范）。

- 机器人统一称为「bot」，不使用「她」；中文与英文、数字之间留一个半角空格。
- 不直接称呼「你」：操作说明用「点击……」「请……」等中性句式，需要指代使用者时用「主人」。
- 表示操作用「点击」「填写」「选择」，表示状态用「尚未」「暂无」「无法」「已」等书面词。

## 记忆脑图

「记忆」页的脑图在 canvas 上自绘，不引第三方库：2D 为力导向布局，3D 为同一套布局加上透视投影和缓慢自转（拖动旋转，系统开了减少动态效果时不自转）。
节点颜色用 `--mc-*` 变量（低饱和，深浅色各一套），大小表示重要性，透明度表示保持度；只有画面在显示时才逐帧绘制。

## 品牌图标

控制台侧栏、安装向导、托盘面板顶部都用同一张鱼图标（`app/ui/icon.png`，和窗口、任务栏、托盘图标一致），不用文字方块代替。

## 托盘面板

右键托盘弹出的面板（`app/trayui.py` 窗口、`app/trayart.py` 绘制）沿用同一套颜色、圆角和图标；按显示器缩放比例出图，跟随系统深浅色。画不出来时退回系统菜单。

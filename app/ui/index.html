常用设置

保存时会自动重启 AstrBot，约需半分钟；按 Ctrl+S 也能保存。

访问白名单身份与人设群聊私聊主动消息语音与表情包外观

访问白名单

白名单。bot 不会回复白名单以外的私聊和群，也不会因此产生费用。

管理员可以让 bot 发说说、修改签名、向其他群发送消息，建议只填写主人自己的 QQ 号。

身份与人设

新开始的聊天使用此人设。已有聊天记录的群和私聊会沿用原来的人设；需要更换时，在「人设 → 会话分配」中单独指定。

群聊

被 @ 时 bot 一定会回复。此项是没有人 @ 时 bot 主动接话的起始概率，数值越高，发言越频繁，费用也越高。默认 5%。
短时间内主动回复的条数上限，用于避免刷屏。默认 4。
在群内回复时引用对方的原消息（QQ 原生引用），消息较多时也能看清 bot 回复的对象。语音回复无法附带引用。
在群内回复时同时 @ 对方，对方会收到提醒。语音回复无法附带 @。
群成员 @ 其他人时，bot 不参与对话。建议开启。
群内约 10 分钟无人发言时，bot 可能主动发起话题；凌晨 1–7 点不触发。
群消息包含这些词时，bot 一定会读取该消息，再判断是否回复。

私聊主动消息

主人一段时间没有发言时，bot 会主动发起私聊；凌晨 1–7 点不触发。

语音与表情包

回复以语音形式发送的概率。未启用语音时，此处显示「未安装」。
每条回复附带一张表情包的概率。默认 20%。

外观

外观设置立即生效，无需点击「保存」，也不会重启 AstrBot。

选择「跟随系统」时，控制台随 Windows 的深色模式设置自动切换。安装向导和托盘面板同步使用此设置；AstrBot 和 NapCat 的原版后台不受影响。

模型与 API

管理模型服务商的连接，并为聊天、识图和各会话指定模型。

已添加的连接

保存连接不会切换正在使用的模型。「验证」会发起一次简短的 API 请求，可能产生极少量用量。

默认用途

默认聊天模型用于未单独指定模型的会话；识图模型的选择会同步到群聊图片描述。

会话单独指定

只列出白名单中的群和私聊。单独指定后，该会话不再跟随默认聊天模型。

群聊 / 私聊聊天模型

人设

人设是写给 bot 的一段设定，用于说明它的身份和说话方式。保存后立即生效。

    支持 UTF-8 编码的 .md / .txt 文件。导入后点击「保存」才生效；导出保存当前编辑正文。仅修改本地文件不会更新正在使用的人设。

    人设只需描述性格和说话方式。识别主人、向群或好友转达消息、查询知识库、修改签名等能力，所有人设都具备。

    会话人设分配

    为群或私聊指定人设后，该会话会一直使用它；未指定时使用默认人设（可在「常用设置」中修改）。关闭「发语音」后，该会话只发送文字。此处只列出白名单内的群和私聊。更换人设后，在该会话中发送一次 /reset 清除原有的聊天上下文，bot 就不会延续之前的语气。

    会话人设语音回复静音

    静音期间，bot 在该群不发言：不读取也不回复任何消息，主动接话、冷场话题和定时消息也不会发送到该群。主人在该群发送「解除静音」即可恢复，也可以通过私聊让 bot 恢复。

    主人吩咐

    为某个群或所有群设置的长期规则，例如「少说话，没人叫你别插嘴」「别提考试的事」。bot 在该群每次回复前都会读取这些规则，保存后立即生效。也可以直接通过私聊告诉 bot，它会自动记录到这里。

    适用范围吩咐

    人设表情包配置

    勾选后，bot 只从所选表情包中选图；一个都不勾选时使用「默认表情包」。表情包随会话使用的人设自动切换，修改后立即生效。

    人设表情包

    新建表情包

    新建的表情包是空的，需要添加图片：进入「AstrBot 管理后台」→ 插件 → 表情包管理器，打开管理页面，选中该表情包后上传图片并分类。请在分类说明中写清使用场合，bot 会根据说明选图。

    知识库

    为 bot 提供资料。群内问到相关内容时，bot 会先查询资料，再组织语言回答。

    全部知识库
    读取中…

    启用的知识库

    bot 只查询已勾选的知识库。

    开启：bot 判断需要时才查询（推荐，闲聊时不会牵扯到资料内容）。关闭：每条消息都先查询一次，费用更高，也容易偏离话题。
    未安装对应插件：「自主学习」依赖大肥鱼插件组，接入时未选择安装。

    自主学习

    主人通过私聊对 bot 说「记一下：……」时，bot 会将内容记入知识库（保存在资料文件夹的「主人补充.md」中，可以随时查看和修改）。群成员的同类指令无效。

    群内有人提出具体问题而知识库中没有答案时，bot 会通过私聊询问主人；主人回答后，bot 将答案记入知识库，并回到群内答复。
    0 表示不限

    记忆

    主人档案、各人设的日记和待跟进事项。每天凌晨自动整理，也可以手动立即整理。

    对象 人设
    拖动平移 · 滚轮缩放 · 3D 下拖动旋转 · 点击节点查看详情

    档案

    关于对方的稳定信息。主人的档案由所有人设共用。「保持度」表示记忆的清晰程度：长时间未被提及的档案会逐渐淡忘，保持度低于一定程度后移入「已淡忘」，可以恢复。

    日记与周记
    读取中…

    待跟进

    带有日期、需要后续关心的事项。到期当天傍晚，bot 会通过私聊询问主人（每天最多两次，主人正在聊天时不打扰）。

    当前注入的记忆

    每次回复前附加在人设之后的内容。同一天内数据没有变化时，这段内容逐字相同，可以命中模型的输入缓存。

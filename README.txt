大肥鱼整合包  v1.5.0
================================

把 DeepSeek 养进 QQ：一个会发表情包、会主动找你、记得你的「大肥鱼」。

【怎么开始】
1. 把整个压缩包解压到一个英文路径、不带空格的文件夹，比如 D:\Dafeiyu
   （别在压缩软件里直接双击运行，要先完整解压）
2. 双击 START.vbs
3. 弹出的「养一条大肥鱼」窗口里，跟着向导一步步点就行，大约 20–40 分钟（主要在等下载）。
   中途关掉也没关系，再双击 START.vbs 会从断的地方继续。

装好以后：桌面上有「大肥鱼控制台」，右下角托盘有一条小鱼（绿色 = 在线）。开机会自动上线。

【你需要准备】
- 一个 QQ 小号，和登着这个小号的手机（扫码用）
- 你自己的 QQ 大号（当她的主人）
- 一个模型服务商的 API Key（向导内置 12 家预设，也支持自定义中转）
- Windows 10 / 11，硬盘留 6GB 以上

【先说风险】
- 腾讯协议不允许用第三方软件登录 QQ、用程序代替人工发消息，小号有被限制或封号的可能。只用小号。
- 模型按用量收费，由所选模型服务商计费。只充小额就是最实在的上限。
- 你的 key 和密码只保存在你自己电脑上。

【给她喂资料（知识库）】
控制台 →「知识库」：新建一个知识库，上传 .md / .txt / .pdf / .docx 资料，
再勾选「让她用哪些知识库」保存。之后群里问到相关的事，她会先查资料再回答。
每个知识库在整合包的「知识库」文件夹里有一个同名文件夹，里面就是资料原稿：
直接在文件夹里改、加、删文件，然后在控制台点「同步文件夹」。
主人私聊跟她说「记一下：……」时，资料类内容（规则、术语等）她会记进知识库（写在那个文件夹的「主人补充.md」里，群里也能查到）；主人本人的信息（学校、口味、习惯等）记进她的记忆，只在私聊里召回。
群里遇到查不到的问题，她可以私聊问主人；开关和每天次数在知识库页面里设。
向量模型用安装时的硅基流动记忆模型就行（免费）；没开记忆的话，先在「AstrBot 全部设置」里加一个 Embedding 模型。

【人设文件】
正在使用的人设保存在 AstrBot 数据库中，本地 .md 文件只作草稿。
控制台 →「人设」可以从 UTF-8 编码的 .md / .txt 文件导入正文，点击「保存」后才生效；也可以导出当前编辑正文。
只修改本地文件不会自动更新正在使用的人设。导出未保存的正文时，文件保存的是草稿。

【她的记忆】
她每天凌晨把前一天的聊天整理成日记，记下关于对方的稳定信息（档案）和有日期的事（待跟进），每次回复时都带上。
主人的档案所有人设共用，日记按人设分开；群里看不到主人私聊的内容。长时间没被提到的档案会慢慢淡忘，被再次提到会加深。
控制台 →「记忆」：用 2D / 3D 脑图查看，修改或删除档案和日记，管理待跟进的事，预览她每次带上的记忆，也可以点「立即整理」。
到了待跟进的日子，她会在傍晚私聊主人问一句；在 AstrBot 后台「插件 → 大肥鱼记忆」里可以改时间或关掉。

【版本与更新日志】
每个版本改了什么见 CHANGELOG.md（控制台「版本与更新」页也能看）。
电脑装了 Git for Windows 的话，控制台会自动给每个版本留一份，「版本与更新」页可以切回旧版本、再回到最新版；
控制台打不开时，双击「版本切换.bat」也能切。

【常见问题】
每条按「现象 → 原因 → 怎么办」写。控制台里出错时会弹出同样的处理办法，照着点就行；看不懂就点「生成问题报告」，把生成的文件发给会的人（QQ 号、群号和密钥会自动隐去）。

■ 双击 START.vbs 没反应
  原因：电脑把 .vbs 文件关联到了别的程序。
  怎么办：右键 START.vbs →「打开方式」→「Microsoft Windows Based Script Host」。

■ 杀毒软件提示有风险、文件不见了
  原因：杀毒软件把整合包里的脚本当成可疑文件隔离了。整合包里只有脚本和官方 Python，AstrBot、NapCat 都从官方地址下载。
  怎么办：1. 打开杀毒软件的「隔离区 / 保护历史记录」，恢复被拦的文件；2. 把整合包文件夹加入信任（排除项）；3. 回到控制台点「重试」。

■ 安装 NapCat 时提示「下载的文件不完整」，或者以前那种黑窗口里出现 7-Zip 报错
  原因：NapCat 从 GitHub 下载，国内要经过加速站，网络不稳时文件只下了一半，解压就会失败。和电脑本身无关。
  怎么办：1. 点「重试」，会删掉坏文件、换一个下载地址重新下（v1.5.0 起会自动重试最多三次）；2. 还不行就换个网络（比如手机热点）再试；3. 平时开代理或加速器的，打开后再试。

■ 安装 AstrBot 时卡住或报「安装组件失败」
  原因：多半是国内软件源暂时连不上，少数是硬盘空间不够。
  怎么办：1. 回到「安装位置」那一步点「检查」，看网络和硬盘两项是不是打勾；2. 点「重试」，会自动换软件源；3. 还不行就生成问题报告。

■ 她不回消息
  原因：常见的有四种：AstrBot 没在跑、小号登录过期、DeepSeek 没余额、这个群或人不在白名单。
  怎么办：控制台「总览」→「故障诊断」→「开始诊断」。每个问题下面都有按钮（启动 AstrBot、扫码登录、去充值、常用设置），点了会直接去做，做完自动再诊断一次。

■ 提示小号要重新扫码
  原因：QQ 登录状态过期，或者在别的设备登过这个号。
  怎么办：点「扫码登录」，用登着小号的手机 QQ 摄像头扫码，手机上确认。截图扫不了。

■ DeepSeek 余额不足 / 密钥不对
  原因：余额用完了，或者 key 被删、复制时少了字符。
  怎么办：余额不足就点「去充值」，几分钟内恢复；key 不对就去 DeepSeek 密钥页新建一个，到「常用设置」里换上。

■ 更新完整合包后，插件页面打不开或者提示「重启 AstrBot」
  原因：有些改动要 AstrBot 用新设置重新启动一次才生效。
  怎么办：更新内容的弹窗里会列出「更新后还要做的事」，点「重启 AstrBot」，做完会自动打勾。重启时她大约一分钟不回消息。

■ 私聊叫她往群里发消息，她说不会
  原因：她不在那个群里，或者叫她的人不是主人。
  怎么办：确认她在群里，并且你的 QQ 号在「常用设置」的主人里。v1.3.0 起换了人设也能发。

■ 想让她在某个群别说话
  怎么办：私聊跟她说「别在 XX 群说话」，或在群里叫她闭嘴，她会真的静音；在群里发「解除静音」恢复。也可以在「人设 → 会话分配」里开关。

■ 更新 AstrBot / NapCat
  怎么办：控制台「版本与更新」页一键更新，不要在 AstrBot 管理后台里点更新（会和整合包对不上）。

■ 想彻底删掉
  怎么办：控制台 →「版本与更新」→「完全卸载」，然后删掉整合包文件夹。

【组成与许可】
- AstrBot（AGPL-3.0）、NapCat：安装时从官方地址下载，不随包分发。
- 大肥鱼配置包（MIT，作者 zexuanw958-svg，github.com/zexuanw958-svg/dafeiyu-config-pack）：人设、插件设置和导入工具。

【模型与识图】
控制台 → 模型与 API → 添加连接。预设填写 API Key 即可；自定义中转需填基础地址、接口协议和模型 ID。
保存连接后，可先点「验证模型」，再分配到默认聊天、识图或某个群/私聊。验证会调用一次模型；保存连接不会切换原会话。
识图能力取决于具体型号，改型号后请重新确认。选择识图模型会同步到群聊图片描述；普通图片不会套用万象棋规则。

【缓存与用量】
用量与费用 → 输入缓存占比 = 缓存输入 /（未缓存输入 + 缓存输入）。回复数可能含多轮工具请求，且可能漏掉接话判断、记忆整理和部分测试，不等于完整账单。
固定人设与规则保持在提示前段，变化的记忆与当前内容放后段；同一会话持续使用同一模型更利于复用缓存。不要为缓存命中率保留无用的长内容。
缓存能节省部分重复输入的计算和费用，逻辑 token 数量仍会计入用量。各家缓存门槛、有效时间和价格不同，费用以服务商账单为准。

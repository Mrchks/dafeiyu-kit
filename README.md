# 大肥鱼整合包

面向普通用户的 QQ 智能伙伴整合包：通过图形化控制台完成安装、配置与日常维护，让接入 QQ 的大模型具备长期记忆、群聊协作能力与可控的使用成本。

## 项目简介

大肥鱼整合包由三部分组成：

- **桌面控制台**（本仓库）：安装向导、运行管理、记忆与知识库管理、模型与费用管理、故障诊断与更新。
- **配套插件组**（本仓库 `app/configpack/`）：记忆、知识库检索、群聊行为修正等自研 AstrBot 插件，由控制台自动安装和升级。
- **运行底座**：[AstrBot](https://github.com/AstrBotDevs/AstrBot)（机器人框架）与 [NapCat](https://github.com/NapNeko/NapCatQQ)（QQ 协议端），安装时从官方渠道下载，不随包分发。

AstrBot 与 NapCat 解决「能否接入」的问题；本项目解决接入之后的问题：如何让 bot 记住人、在群里行为得当、成本可控，并且在出现故障时由非技术用户自行处理。

## 核心功能

### 一、分层记忆系统

记忆系统为自研实现，采用「常驻档案 + 每日日记 + 待跟进事项」三层结构，由后台任务定时整理，无需人工维护。

| 能力 | 说明 |
|---|---|
| 档案 | 从聊天中提取关于对方的稳定信息（称呼、偏好、近况等）。每条档案须附带聊天原文作为依据，避免模型臆造。 |
| 日记与周记 | 每日凌晨将前一天的聊天整理为日记，并按周合并为周记，可按日期回答「昨天聊了什么」一类问题。 |
| 遗忘与强化 | 档案按保持度随时间衰减，长期未被提及的内容移入「已淡忘」并可恢复；再次提及会强化。生日、称呼等永久信息不衰减。 |
| 约定跟进 | 聊天中出现的考试、面试、出行等带日期事项会被记录，到期当日傍晚主动私聊询问，每日不超过两次。 |
| 范围隔离 | 主人档案由所有人设共用，日记按人设区分；群聊只能读取本群的档案与日记，无法读取主人私聊内容。 |
| 可视化管理 | 「记忆」页提供 2D / 3D 脑图、档案与日记编辑、待跟进管理、注入内容预览、立即整理与回放测试。 |

### 二、群聊能力

- **会话级人设与模型分配**：每个群、每个私聊可分别指定人设和模型，互不影响。
- **群聊静音**：主人通过私聊或群内指令让 bot 在指定群停止发言，支持定时恢复；静音期间不读取、不回复、不主动发言。
- **主人吩咐**：为单个群或全部群设置长期规则（例如「少发言」「不讨论考试」），每次回复前生效。
- **知识库自动检索**：消息命中知识库中的术语、别名或关键词时，自动附带相关资料后再回答；资料中没有的内容如实说明，或私聊向主人求助。
- **群聊识图**：修复上游组件在纯图片消息下无法识图的问题，并支持为识图单独指定模型与识别规则。
- **真实记录查询**：主人询问 bot 在某个群的发言时，读取真实聊天记录后作答。
- **表达控制**：引用回复、回复时 @ 发送者、@全体成员（仅主人可触发）均可分别开关。

### 三、知识库

- 支持 .md / .txt / .pdf / .docx 资料；每个知识库对应一个本地文件夹，修改文件后在控制台「同步文件夹」即可生效。
- 主人私聊说「记一下」时自动分流：个人信息写入记忆，规则、术语等资料类内容写入知识库。
- 可设置按需检索或每次检索，并限制 bot 每日向主人求助的次数。

### 四、模型与成本管理

- **多服务商接入**：内置 OpenAI、Anthropic、DeepSeek、Kimi、Gemini、Grok、Qwen、Doubao、MiniMax、MiMo、GLM、LongCat 共 12 家预设，并支持自定义中转地址、接口协议与请求参数；API Key 保存后不回显。
- **配置时即可检测**：填写密钥后直接请求服务商，未保存前即可确认密钥是否有效、读取可选模型；失败时区分密钥、地址与协议、余额与限流、网络、证书与代理等原因。思考程度以分段选项选择，由控制台换算为各服务商的实际参数；安装向导同样可以检测。
- **按用途分配模型**：默认聊天、识图、各群与各私聊可分别指定模型，保存连接不会改变已有会话的分配。
- **缓存优化**：固定系统提示与工具列表的顺序和内容，将时间、情绪、检索结果等易变内容移至当轮消息，并调整历史截断策略，以提高服务商的输入缓存命中率、降低重复输入的费用。
- **用量统计**：按人、按群合并统计 token、调用次数与估算费用，支持今天 / 7 天 / 30 天 / 全部时段，并展示输入缓存占比。

### 五、人设与对话测试

- 人设在控制台内编辑，支持从 .md / .txt 文件导入、导出；表情包可按人设分别配置。
- 「对话测试」可选择私聊或群聊场景、人设、模型与对方身份进行模拟，仅生成文字，不向 QQ 发送消息，也不写入记忆。

### 六、安装与运维

- **安装向导**：图形化分步安装，支持断点续装；下载后校验完整性，失败时自动更换加速地址；默认端口被系统占用时自动切换。
- **运行监控**：统一管理 AstrBot 与 NapCat 进程；看门狗识别掉线原因（账号在其他设备登录、登录过期、进程退出、连接中断）并发出通知，可设置开机自启与掉线自动重启。
- **故障诊断与问题卡**：一键诊断运行状态、QQ 连接、模型余额、白名单与近期报错；操作失败时以「问题卡」说明原因并给出处理步骤与对应按钮。
- **问题报告**：一键生成诊断压缩包，QQ 号、群号、密钥、系统用户名与后台账号均已脱敏。
- **更新与回退**：AstrBot、NapCat 与控制台均可一键更新，更新前自动备份，新版本无法启动时自动回退；控制台更新包带 Ed25519 签名并校验 sha256，校验不通过时不会安装。
- **备份与日志**：人设、记忆、知识库与设置可备份和还原；日志可按时间段查看、筛选异常并脱敏导出。
- **问题反馈**：在控制台内直接向作者提交问题或建议，可选择附带问题报告；提交前可核对将发送的全部内容。

## 与直接使用开源组件的差异

| 环节 | 直接使用 AstrBot + NapCat | 大肥鱼整合包 |
|---|---|---|
| 安装 | 自行安装运行环境并配置两者之间的连接 | 图形向导，断点续装，自动处理下载与端口问题 |
| 记忆 | 自行选择并配置记忆插件 | 自研分层记忆，自动整理、遗忘与跟进，可视化管理 |
| 群聊 | 自行组合插件并调试 | 内置静音、主人吩咐、知识库自动检索、识图修复 |
| 成本 | 无统一统计 | 缓存优化，按人、按群统计用量与费用 |
| 故障 | 查阅日志自行排查 | 诊断、问题卡、脱敏问题报告、自动回退 |
| 更新 | 分别在各自后台操作 | 统一入口，一键更新并可回退 |

## 快速开始

1. 在 [Releases](https://github.com/Mrchks/dafeiyu-kit/releases) 下载最新的完整包 `Dafeiyu-Kit-vX.Y.Z.zip`。
2. 完整解压至英文路径且不含空格的文件夹，例如 `D:\Dafeiyu`。
3. 双击 `START.vbs`，按安装向导操作，全程约 20–40 分钟，主要为下载耗时。

安装前需准备：

- 一个 QQ 小号，以及已登录该小号的手机（用于扫码）；
- 主人使用的 QQ 号；
- 任一模型服务商的 API Key；
- Windows 10 / 11，磁盘可用空间不少于 6 GB。

### 已在使用 AstrBot 和 NapCat

在安装向导第一步选择「接入已有的 AstrBot 和 NapCat」：控制台自动查找本机的安装位置（AstrBot 启动器实例、源码或 pip 安装，Shell 版 NapCat），原位接管，不移动、不覆盖原有数据，改动前自动备份配置文件。插件组、人设和推荐设置均由用户勾选，推荐设置逐项列出当前值与推荐值。AstrBot 需要 4.26.0 或更高版本；暂不支持 Docker 部署、非 Windows 系统和非 Shell 版 NapCat。「解除接入」只移除控制台自身的快捷方式、自启和状态，不删除原有安装。

详细说明与常见问题见包内 [README.txt](README.txt)，版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 风险提示

- 腾讯用户协议不允许使用第三方软件登录 QQ 或以程序代替人工收发消息，bot 使用的账号存在被限制或封禁的风险，**请仅使用小号**。
- 模型调用按用量计费，费用由所选服务商收取，建议小额充值并留意「用量与费用」页。
- API Key、密码、聊天记录与记忆数据仅保存在用户本机；仅在用户主动提交问题反馈时，才会发送用户确认过的内容。

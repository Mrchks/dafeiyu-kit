# 大肥鱼整合包

把 DeepSeek 等大模型养进 QQ：一个会发表情包、会主动找你、记得你说过的事的「大肥鱼」。

面向不懂技术的用户：解压、双击、跟着向导点，20–40 分钟装好，之后在桌面控制台里管理一切。

## 它和直接使用开源组件有什么不同

[AstrBot](https://github.com/AstrBotDevs/AstrBot)（机器人框架）、[NapCat](https://github.com/NapNeko/NapCatQQ)（QQ 协议端）和各家大模型都可以免费获得。本项目不重复造这些轮子，而是补上「普通人从装上到长期养好」中间缺失的部分：

| | 直接使用开源组件 | 大肥鱼整合包 |
|---|---|---|
| **安装** | 自行安装环境、配置 OneBot 反向连接、处理国内网络 | 图形向导，断点续装；下载校验并自动切换加速站；端口被占用时自动避让 |
| **稳定运行** | 两个后台各自管理，掉线需翻日志 | 统一管理两个进程；识别掉线原因（被挤下线、登录过期、进程退出）并给出处理按钮 |
| **像人一样相处** | 需自行挑选、组合插件 | 自研分层记忆（档案、日记、待跟进、遗忘曲线、凌晨整理、约定后主动跟进）；聊到游戏自动查知识库；群聊识图修复；人设导入导出；对话测试与回放测试 |
| **费用** | 无统计 | 固定提示结构以提高缓存命中；按人、按群统计用量与费用 |
| **出了问题** | 自行排查 | 报错转为带操作按钮的问题卡；一键诊断；一键生成已脱敏的问题报告；AstrBot / NapCat 一键更新与回滚；控制台版本切换 |

## 下载与安装

1. 在 [Releases](https://github.com/Mrchks/dafeiyu-kit/releases) 下载最新的 `大肥鱼整合包-vX.Y.Z.zip`。
2. 完整解压到英文路径、不含空格的文件夹（例如 `D:\Dafeiyu`）。
3. 双击 `START.vbs`，按向导操作。

需要准备：一个 QQ 小号（及登录该小号的手机）、你自己的 QQ 大号（作为主人）、一个模型服务商的 API Key；Windows 10 / 11，硬盘预留 6GB 以上。

详细说明、常见问题见包内 [README.txt](README.txt)，各版本改动见 [CHANGELOG.md](CHANGELOG.md)。

## 风险说明

- 腾讯协议不允许使用第三方软件登录 QQ、以程序代替人工收发消息，**机器人号存在被限制或封号的可能，请只用小号**。
- 模型按用量收费，由所选服务商计费，建议小额充值。
- API Key 和密码只保存在你自己的电脑上。

## 仓库结构

- `app/`：桌面控制台（Python 后端 + `app/ui/index.html` 前端）
- `app/configpack/`：随包分发的配置、人设和自带 AstrBot 插件
- `tests/`：离线回归测试
- `docs/`：开发文档（不随发布包分发）

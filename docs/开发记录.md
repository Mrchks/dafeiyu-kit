## v1.5.0 · 2026-11-03
### 记忆系统
设计依据：「常驻分层 + 后台整理 + 按需查档」（参考 ChatGPT 常驻事实与近期摘要、Letta 睡眠代理、Mastra 观察式记忆；DeepSeek flash 缓存命中价约为未命中的 1/50）。
- 插件 astrbot_plugin_dafeiyu_memory（always_reinstall）：memcore.py 纯逻辑（插件和控制台共用），SQLite 表 messages / diaries / facts / followups / names / history / jobs / meta。
- 对象 scope：owner、u:QQ、g:群号。档案按对象（主人档案所有人设共用）；日记、周记按（对象, 人设）。私聊范围看不到群日记，是设计如此。
- 写入门：档案必须带当天原文里逐字存在的原话；相似度 ≥0.75 视为再次提到；每天最多 8 条；控制台改过的日记不覆盖。
- 遗忘：R = 0.5^(天数/半衰期)，永久不衰减，长期 180、一般 30、临时 3 天；R<0.08 归档；档案 800 字、时间线 1500 字上限。
- 注入：档案、最近 7 天日记 + 周记、待跟进、使用说明、相处原则（危机时 12356）。同一天数据不变逐字相同。
- 后台：每天 4 点整理；今天停聊 90 分钟且新消息 ≥8 条先写一版；周记合并；30 天原文清理；约定跟进 19:30–22:30 主动私聊（每天 ≤2 次）。
- 工具：memory_save、memory_forget、memory_search、read_diary、followup_add。
- 控制台「记忆」页：脑图 2D/3D、档案、日记、待跟进、预览与测试、立即整理。
- 实测（作者环境 22:54 立即整理）：62 条消息 → 2 篇日记（群「一轮游陪玩团」大肥鱼、主人 小柚）、4 条群档案，注入预览正常。群档案偏琐碎（如「群友认为班叔是区」），以后可收紧群聊的写入门。
- 回放测试（作者环境）：「今天晚上你给我发过什么消息」「我上午回你消息了吗」都按日记答对。她用语音回答时只拿到「[语音]」；换新对话重问（最多 3 次）的修复在 1.5.1。对话测试里她会怀疑对方不是主人（网页对话不是主人 QQ）。
- plugin_sync.migrate：第 2 项 LivingMemory top_k=0、关 memorize；第 3 项群聊识图。kb 插件 v0.1.3 用 memory_save。

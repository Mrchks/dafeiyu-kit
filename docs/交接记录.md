格式：

```
## 2026-11-08 · Claude · 实现 · 任务名
- 做了什么：一两句话
- 改了哪些文件：
- 怎么验证的：跑了哪些测试、界面看了哪里；没验证的写明
- 提交：提交说明的第一行（短号用 `git log` 查）
- 没做完 / 需要注意：
- 下一步建议：
```
